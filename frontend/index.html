Media Studio

Image, video, lip-sync & cinema workflows — powered by media_studio module. Add API keys in Settings → Media Studio API Keys to auto-submit; otherwise you get ready prompts.

How Media Studio works — click to expand
What it is: a lightweight media workflow that builds image, video, lip-sync, and cinema prompts via the media_studio module — no heavy models load into RAM. If API keys are set in Settings → Media Studio API Keys, prompts auto-submit to the provider (Gemini / Vercel AI Gateway / Freepik); otherwise you get ready-to-paste prompts.

The four tools:
🖼 Image prompt — visuals, product shots, posters, concept art
🎞 Video prompt — motion clips with camera-movement directions
👄 Lip sync — character/voiceover lip-sync scene prompts
🎬 Cinema shot list — camera angles, lenses, lighting & shot breakdowns

PersonaLive (optional module): live-portrait / lip-sync / talking-head workflows via persona_live — set PERSONALIVE_URL or vault personalive_url (default 127.0.0.1:7860); mock-safe when the service isn't running. See github.com/GVCLab/PersonaLive.

ᛗᛁᚨᛋᛗᚨ · Getting started
      
first-run guide

      
    

    

      
No models found yet? You can install and pull open-source models with tools like
      Ollama — downloaded models follow the standard guidelines/policies of their sources.
      Models you train or build yourself are not restricted by those download policies and are
      not blocked here.

      
This version focuses on text models; a future release will add image generation.

      
Choose models suited to your RAM, CPU, and GPU — ᛗᛁᚨᛋᛗᚨ can still handle and
      control even very large models.

      
Any downloaded model can be connected — including massive ones such as
      Kimi K3 (~2.8T total / ~50B active), DeepSeek-V4 Pro (1.6T),
      GLM-5.2 (744B MoE), Nemotron 3 Ultra (550B), and MiniMax M3.

      
There is no token limit imposed by the app — full capabilities tailored to the
      connected model: app development, single tasks, and multi-step workflows, locally or via
      cloud setups with API keys.

      

      Developer note: this version may still have errors or bugs — the full
      all-platform experience is under active development. It is not free right now, but the
      developer is actively working to make it available for free.

      
Note: the Auto button frees RAM by unloading idle models —
      the screen may become slightly dimmer while it runs, and your already-open
      apps are never affected or closed.

      
If you run into any issue or error, please post a message/issue on GitHub:
      github.com/DewTechAI
